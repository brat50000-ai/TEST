# Telegram-бот с ИИ

Личный бот на Node.js ([grammY](https://grammy.dev)):

- ведёт диалог через **Claude Sonnet 5.5** (Claude API) и помнит разговор (история хранится в `data/history.json`,
  длинные диалоги автоматически сжимаются на стороне Claude);
- читает документы: PDF, картинки/фото, текстовые файлы (txt, csv, json, md, код и т. п.);
- понимает голосовые: расшифровывает их моделью OpenAI **gpt-transcribe** и отвечает на текст;
- ищет свободное время для гольфа (tee time) на полях **Troon** (сайт [golfwithaccess.com](https://golfwithaccess.com),
  приложение Access by Troon): «хочу завтра утром поиграть в Скоттсдейле на двоих», и бот присылает ближайшие поля,
  свободное время и цены, а также ссылку, по которой открывается страница поля с этой датой;
- отвечает только пользователям из `ALLOWED_USER_IDS`.

Команды: `/start` — о боте, `/new` — начать новый диалог.

## Запуск в облаке с iPad (Railway)

Компьютер не нужен: всё делается в браузере.

1. Зайдите на [railway.com](https://railway.com) и войдите через GitHub (тариф Hobby — около $5 в месяц).
2. **New Project → Deploy from GitHub repo** и выберите этот репозиторий. Railway сам найдёт `Dockerfile`.
3. В сервисе откройте **Settings → Source → Branch** и выберите ветку, в которой лежит бот.
4. Во вкладке **Variables** добавьте `BOT_TOKEN`, `CLAUDE_API_KEY`, `OPENAI_API_KEY` и `ALLOWED_USER_IDS`
   (значения те же, что в `.env.example`).
5. Необязательно, но полезно: **правый клик по сервису → Attach Volume**, путь монтирования `/app/data`.
   Тогда история диалогов не будет теряться при перезапуске.
6. Нажмите **Deploy**. Во вкладке **Deployments → View logs** должна появиться строка «Бот @… запущен».

Открывать порт и настраивать домен не нужно: бот сам опрашивает Telegram.

## Запуск на своём компьютере

1. Установите Node.js 22+ (проверено на v26.13.1).
2. `npm install`, затем `npx playwright install chromium` (браузер для чтения расписания Troon)
3. Скопируйте `.env.example` в `.env` и заполните: токен от @BotFather, ключ Claude API, ключ OpenAI API,
   свой Telegram ID (бот покажет его, если написать ему с чужого аккаунта).
4. `npm start`

Необязательные переменные: `CLAUDE_MODEL` (по умолчанию `claude-sonnet-5-5`),
`OPENAI_TRANSCRIBE_MODEL` (по умолчанию `gpt-transcribe`).
Если задана `HTTPS_PROXY`, бот обращается к Telegram, Claude и OpenAI через этот прокси.

## Как устроен поиск Troon (`troon.js`)

- Список полей берётся из публичного sitemap сайта, а город, координаты и id полей — со страниц полей.
  Всё это сохраняется в `data/troon-courses.json` и обновляется раз в неделю. Первая сборка занимает около 40 секунд.
- Свободное время сайт показывает только обычному браузеру, поэтому бот открывает страницу поля
  с нужными датой, числом игроков и временем в headless Chromium (Playwright) и читает данные, которые загружает сама страница.
  Одновременно открывается не больше 3 страниц; после 5 минут простоя браузер закрывается.
- Бронирование и оплату бот не делает: он даёт ссылку на страницу поля, где вы выбираете время
  и платите картой или баллами Access в своём аккаунте.
